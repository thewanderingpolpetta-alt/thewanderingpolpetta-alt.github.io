Real apps with Vercel

Login, a database and private code, still free and still on GitHub.

    Behind the scenes

    • Vercel's free Hobby plan is for personal, non-commercial projects.
    • Vercel connects to GitHub, so the repository can stay private and every push still keeps its history.
    • Google sign-in comes from a login library (e.g. Auth.js or Clerk) plus a Google Cloud sign-in key.
    • Databases come from Vercel's Marketplace (e.g. Neon Postgres or Supabase), which have free tiers.
    • Secrets like keys go in Vercel's environment variables, never in the code.
    • Vercel's built-in site-wide password is a paid add-on. On the free plan, require sign-in instead (e.g. only allow certain Google accounts).
